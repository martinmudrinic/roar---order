# Roar & Order 🍕

Full-stack pizza ordering web application built with:

- PHP
- MySQL
- JavaScript
- CSS
- PDO
- Sessions

## Features

- Dynamic pizza menu
- Live order calculations
- Toppings and extras
- Pickup and delivery
- Admin login
- Price management
- Receipt system
- Database persistence


## Setup

1. Import `pizza_ordering.sql`
2. Update database credentials in `dbConn.php`
3. Open the project in browser
