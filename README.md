# Roar & Order 🍕

Full-stack pizza ordering web application built with:

- PHP
- MySQL
- JavaScript
- CSS
- PDO
- Sessions

## Features

- Dynamic pizza menu
- Live order calculations
- Toppings and extras
- Pickup and delivery
- Admin login
- Price management
- Receipt system
- Database persistence
